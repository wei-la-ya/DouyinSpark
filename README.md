## 丨安装提醒

>
> **运行环境要求 Python `3.11+`**

## 使用提醒

由于网页链接具有隐私性，扫码登录抖音账号，添加好友可看到好友名称，更改续火文案，故在群聊内使用dy添加账号，添加好友等隐私命令，会将网页链接发送进对应用户的私聊，若失败则降级为发送qq邮箱，请确保已配置smtp相关配置


> 首次使用登录功能前，请确认 Core 的 Web 服务可以被浏览器访问或部署[外置服务](https://github.com/wei-la-ya/douyin-spark-login)并在插件配置内进行填写配置**服务地址**并打开外置服务开关。
>若不是外置服务，则无需打开开关，仅配置自定义地址即可，此插件网页挂载在core的路由上，请确保外部设备可访问core的端点
> 🚧 插件仍在持续完善中 🚧
